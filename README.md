# 🚢 MARINE RAG — 선박기기 매뉴얼 RAG 안내 챗봇

> 선박기기 매뉴얼 PDF를 **완전 로컬**로 색인·검색하고, **근거 기반(RAG)** 으로 답해 주는 도구.
> 스캔본/텍스트본 PDF를 모두 지원하며, **한글로 물어도 영문 매뉴얼**이 매칭됩니다. (예: `산소 분석기` → `oxygen analyzer`)

---

## ✨ 기능

- **하이브리드 검색** — 도면·표(이미지) + 본문(다국어 텍스트)을 동시에 검색
- **근거 기반 답변 (폐쇄형 RAG)** — 로컬 LLM이 **검색된 근거만으로** 답하고, 근거가 없으면 지어내지 않고 "확인되지 않습니다"
- **출처·그림** — 답변에 `[출처 파일 · p쪽]` 인라인 인용, 관련 도면·표는 클릭해 확대
- **구조화 청크 산출물** — 색인 시 `chunks.jsonl` + `verify_report.md` 자동 생성
- **완전 로컬** — 외부 통신 없이 동작(모델 가중치만 최초 1회 다운로드). 유료 API는 선택·수동

## 🖥️ 화면 (탭)

| 탭 | 설명 |
|---|---|
| 📁 색인 생성 | PDF 드래그앤드롭 → 이미지+텍스트 색인, 세트별 관리(추가/덮어쓰기) |
| 🔍 하이브리드 검색 | 질의어로 도면·표 + 본문 동시 검색, 출처·페이지 표시 |
| 💬 챗봇 (RAG) | 근거 기반 답변 생성, 인용·연관 근거·그림, 멀티턴 토글 |

> 스크린샷은 [`screenshots/`](screenshots/) 참고.

## ⚙️ 구성

| 역할 | 사용 |
|---|---|
| 이미지 임베딩 | `google/siglip2-base-patch16-224` (SigLIP2) |
| 텍스트 임베딩(다국어) | `BAAI/bge-m3` (교차언어, 1024차원) |
| 도면·표 검출 | DocLayout-YOLO |
| OCR(스캔본) | RapidOCR → EasyOCR (한글+영어) |
| 생성 LLM | **Ollama `qwen3.5:2b`** (로컬) |
| UI / 실행환경 | Gradio · **CUDA / Apple MPS / CPU 자동 감지** |

## 📦 설치

**1) 파이썬 패키지**
```bash
pip install -r requirements.txt
```
> NVIDIA GPU에서는 torch를 CUDA 빌드로 교체하세요 — `requirements.txt` 주석 참고. (macOS는 MPS 자동)

**2) 생성용 로컬 LLM (Ollama)**
```bash
ollama pull qwen3.5:2b
```
> [Ollama](https://ollama.com)를 설치·실행해 두면 챗봇 탭이 `http://localhost:11434`로 호출합니다. (환경변수 `OLLAMA_HOST`로 변경 가능)

## ▶️ 실행

```bash
python app.py
```

| 옵션 | 설명 |
|---|---|
| (없음) | 로컬 전용 `http://127.0.0.1:7860` (브라우저 자동 열림) |
| `--host 0.0.0.0` | 사내망(LAN) 공유 |
| `--share` | 임시 공개 링크(시연용) |
| `--port <번호>` | 포트 변경 (기본 7860) |

> Windows는 `run.bat`(로컬) / `run_share.bat`(공유) 더블클릭으로도 실행됩니다.

## 🧭 사용 순서

1. **📁 색인 생성** 탭에서 매뉴얼 PDF를 올리고 세트 이름을 정해 색인
2. **🔍 하이브리드 검색** 또는 **💬 챗봇** 탭에서 세트를 고르고 질문
3. 챗봇은 근거로 답하며 `[출처 파일 · p쪽]`과 관련 그림을 함께 제시 (근거가 없으면 답을 만들지 않음)

## 🗂️ 청크 산출물 (색인 시 자동 생성)

색인하면 세트 폴더에 다음이 생성됩니다:

- `indexes/<세트>/chunks.jsonl` — 청크당 `id · text · url(파일#page) · section` (+ `char_len·ocr·flags`)
- `indexes/<세트>/verify_report.md` — **중복 가능 청크** 목록 + **사람이 원문 확인할 항목**(플래그별)

> 청크 규칙·필드 상세는 [`PRD.md`](PRD.md) §4.1 참조.

## 🔒 보안

- 기본은 **완전 로컬**입니다. 실제 선박 매뉴얼은 **로컬/사내망**에서만 사용하세요.
- 챗봇 **'고급' 설정에서 API로 수동 전환**할 때만 외부 호출이 일어나며, 이 경우 **검색된 매뉴얼 내용이 외부 서버로 전송**됩니다(전환 시 경고 표시). 보안 자료에는 사용하지 마세요.
- 원본·색인 데이터(`indexes/`, `*.pdf`, `crops/`, `pages/`)는 `.gitignore`로 저장소에서 제외됩니다.
