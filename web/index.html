🚢 선박기기 매뉴얼 RAG 안내 챗봇 (웹 데모)

매뉴얼 근거 안에서만 답합니다(폐쇄형). 답변엔 [출처 파일 · p쪽] 인용 + 자동 근거 판정이 붙고, 근거가 없으면 "확인되지 않습니다"로 답합니다.
로딩 중…
🔗 사용·연관 근거
질문하면 사용된 근거가 표시됩니다.
⚙️ 사용 조건 (숨기지 않습니다)
  1. 답변 생성은 사용자 본인 PC의 Ollama가 담당합니다 — ollama pull qwen3.5:2b 후 Ollama 실행.
  2. 첫 방문에 임베딩 모델(수백 MB)이 브라우저로 다운로드됩니다(진행률 표시). 이후 브라우저 캐시.
  3. 배포(HTTPS) 사이트에서 생성하려면 node web/ollama-proxy.mjs 실행(브라우저 PNA 우회). 로컬 npm run preview는 불필요.
  4. 자동 판정(Judge)은 답변이 근거에 뒷받침되는지 별도 LLM이 평가한 결과입니다. 문장이 매끄러운 것과 근거 있는 답은 다르므로 칩으로 구분해 보여줍니다.
근거 데이터는 공개용 합성 샘플 매뉴얼입니다(실제 보안 매뉴얼 아님).
